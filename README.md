## 这是什么

米白、黑字与暗红的网络文化阅读站，提供免费全文阅读、章节搜索、字号调整、插图放大、阅读进度、娱乐测试与分享卡。题库涉及薄肌、大水、孙学、力工和消费标签等网络话题。

测试是娱乐与自我反思工具，不是心理诊断；原创改编与真实引用按数据中的状态区分。AI 参与了代码和部分文案制作。书稿人物的虚构说明保留在正文中。并非所有语录都已通过完整原始音视频核验。

## 本地运行

安装 Node.js 20 或更新版本，下载仓库并解压，在此目录运行：

```sh
npm start
```

打开终端显示的 http://127.0.0.1:4317/ 。无第三方依赖，无需 npm install。预览仅监听本机；终端关闭后本地地址会停止服务。端口占用时可通过 BOJI_PREVIEW_PORT 环境变量更换端口。

## 修改与部署

- 页面：index.html、app.js、logic.js、motion.js、album.js。
- 样式：style.css、meme.css、mobile.css。
- 书稿、题目、语录：data/ 下对应文件；图片用途统一由 data/assets.json 管理。
- 图片：assets/images/；手机缩略图：assets/thumbs/。同名替换时同时更新两处；保留原图比例。缺图回退和重试逻辑在现有页面中。
- 此仓库根目录也是可部署的静态站点；server.mjs 仅用于本地预览。发布代码不会自动更新当前线上网站。

答案和阅读进度保存在访客本机浏览器，可在站内清除。无需注册、不收手机号、没有真实支付，也不上传测试答案。
